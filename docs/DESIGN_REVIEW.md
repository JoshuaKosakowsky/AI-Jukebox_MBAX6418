# Submission design: Cover Gallery

Joshua selected **Cover Gallery** on 2026-11-02 America/Denver after the
six-layout comparison. The submission uses this layout throughout; the layout
chooser is removed. Old layout query parameters and saved layout preferences
cannot change it. **Appearance** still offers Light/Dark, defaults to Dark and
remembers only the theme. No new generation or media is needed for this choice.

Launch from the README or a clean extracted GitHub ZIP with
`python scripts/dev.py`. Open http://127.0.0.1:8000/ (or your selected port).

1. Find/play a bundled song, pause it and open a vocal lyric panel.
2. Switch Light/Dark; confirm playback position and any song draft survive.
3. Open Create a song, remix an idea and edit it without generating.
4. Find Queue & DJ, presentation and speaker settings; check a narrow window.
5. Report contrast, scrolling or control-discovery findings on
   [issue #9](https://github.com/JoshuaKosakowsky/AI-Jukebox_MBAX6418/issues/9).

Earlier A-F comparison results/screenshots remain historical evidence of the
prototype stage. They are not current navigation instructions or independent
release acceptance. The unused prototype CSS stays in place to keep this
submission change small; only Gallery is exposed by the current interface.
